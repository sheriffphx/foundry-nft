an NFT is known as a non-fungible token. It's a token standard. And it's a unique one. 
No same NFT can occur twice . Sold on DEXes like opensea.io etc. Decentraliztion.
The standard for NFTs is ERC-721(basis). There is also another one ERC-1155(semi-fungible).
Each token in721 is unique with a specific Unique Id. Token URI - a universal URI that contains the 
description of each ERC-721 NFT. 
To make an NFT :
    * Get IPFS
    * Add tokenURI.json file to IPFS
    * Add IPFS URI to your NFT URI
URI : "UNIFORM RESOURCE IDENTIFIER". Every new token minted must point to a specific URI.
